# 三分六合彩 极速混合精度版 v24

目标：快，同时不把一万多期历史价值扔掉。

实时预测路径：
- 最近1200期：负责快速变化、转移、冷热、波色、大小单双、头数、尾数
- 最近700个状态：负责下一期状态转移
- 每期开奖后秒级重算

长期历史路径：
- 完整历史在后台只扫描一次
- 生成长期特码频率先验
- 生成“上期生肖 -> 下一期号码”长期转移先验
- 生成“上期生肖 -> 下一期生肖”长期转移先验
- 缓存在内存，不会每期重新扫一万多条
- 新期开奖只做O(1)增量更新

最终评分：
近期模型负责“跟变化”，全历史先验负责“防止短期噪声带偏”。
全历史只给中等偏小权重，不会把动态预测重新变成死历史频率。

页面启动/开奖更新都不等待全历史扫描。
如果长期先验还没准备好，先使用快速模型；后台准备完成后自动参与后续预测。

速度目标仍然是秒级，不接受分钟级。
注意：更复杂的统计不能保证实际开奖命中率；准确度必须以未来滚动验证为准。
