# 三分六合彩 AI持续学习版 v27

这版才是“AI持续学习”版本。

## AI是什么
不是让程序自己乱改 app.py。
v27加入了一个纯Python在线机器学习模型：Online Softmax Ranker。

它会对49个号码逐个计算特征，然后学习：
“在当前这种历史状态下，哪个号码更应该排前面”。

每期开奖后，AI用真实特码做一次梯度更新，权重会改变并保存到数据库。
下一期预测直接使用更新后的AI权重。

这是真正的在线机器学习，而不是只在5套固定规则之间切换。

## AI学习的特征
每个号码现在有18维特征：
- 近6期特码频率
- 近12期特码频率
- 近24期特码频率
- 近60期特码频率
- 近12期7个位置出现率
- 近36期7个位置出现率
- 遗漏期数
- 状态→下一期号码转移
- 尾数转移
- 全历史长期先验
- 波色走势
- 大小走势
- 单双走势
- 头数强弱
- 冷码指数
- 是否刚开过
- 生肖内历史二选评分
- bias

## 怎么训练
每期开奖：
1. 开奖前已经保存下一期预测
2. 新期开奖到达
3. 用“开奖前的历史状态”构造49个号码的18维特征
4. 真实特码作为正确答案
5. AI执行Softmax交叉熵梯度更新
6. 权重保存进SQLite
7. 再生成下一期24码

绝不会拿刚出的结果去修改上一期预测。

## AI和原算法怎么融合
刚开始AI经验少，不让它独断：
- AI刚启动：约18%权重
- 训练次数增加后逐步提高
- 60次以后最高约50%权重
- 其余仍由统计转移 + 生肖内二选 + 长期历史共同决定

所以它既能学习，又不会因为几期错误把整个预测带偏。

## 历史预训练
如果没有继承到AI权重，后台会：
- 用较老历史做预训练
- 再做最近60期walk-forward历史验证
- 每一期验证都只使用当时之前的数据
- 验证完一期开一次学习更新

页面显示：
- AI训练次数
- AI融合权重
- AI实时24码命中
- AI历史60期验证命中

## 实盘60期验证
每一期AI预测都会在开奖前锁定保存为 `AI在线`。
开奖后自动结算。
页面最多显示最近60期真实前瞻结果。

## 持久学习
AI权重保存在 `ai_model` 表。
`/api/learning-export` 现在会同时导出：
- prediction_log
- AI权重
- AI训练次数
- AI历史验证

以后v28/v29升级时可以直接继承AI的大脑，不重新从零学。

## 关于“AI自己改代码”
我没有让AI直接修改Python源码。
真正需要持续变化的是模型参数和号码排序函数，不是服务框架。
让线上AI任意重写源码会带来崩溃、事后改答案和不可验证的问题。

v27属于：
固定安全框架 + AI持续更新自身模型权重。

注意：AI学习不等于能发现不存在的开奖规律。如果开奖近似随机，模型不会保证命中率持续上升；60期前瞻验证才是判断它有没有实际改善的依据。
