# 三分六合彩 持续学习60期版 v26

这版开始做真正的“预测 -> 开奖 -> 评分 -> 调整模型”的持续学习。

## 为什么不让程序直接重写 app.py
直接让在线程序自己改源代码风险很大：
- 容易把正在运行的网站改坏
- 很难验证它有没有在开奖后“回头改答案”
- 一次错误可能让整个机器人停止

所以 v26 采用更可靠的“模型自修改”：
源代码保持稳定，但模型选择和权重会根据真实结果自动变化，并写入数据库长期保存。
这才是可验证的在线学习。

## 每期开奖前
后台同时保存5套模型对下一期的预测：
- 趋势快
- 平衡
- 热码
- 结构
- 均衡覆盖

每套保存：
- 24个特码
- 4肖1码
- 4肖
- 平特一肖

一旦某期预测保存，使用 INSERT OR IGNORE 锁定，开奖后不能回头改。

## 开奖后自动训练
开奖结果进来后，程序自动给5套模型记分：
- 24码有没有中特码
- 4肖1码有没有中
- 4肖有没有中
- 平特一肖有没有中

然后重算最近60期滚动成绩。

当前学习目标权重：
- 24码命中：88%
- 4肖1码：3%
- 4肖：5%
- 平特一肖：4%

所以训练重点明确放在“抓特码24码”。

## 60期滚动校准
- 不足60期：显示已结算 N/60
- 满60期后：只用最近60期
- 新一期进来，最旧一期自动退出
- 近期表现更好的模型自动成为当前主模型
- 使用贝叶斯平滑，避免刚开始几期0%/100%导致乱跳

## 学习持久化
新增：
- prediction_log：保存每期开奖前的真实预测
- learner_scores：保存模型学习成绩
- /api/learning：查看学习状态
- /api/learning-export：导出学习记录

以后 v27/v28 可以连“学习经验”一起从上一版继承，不只是继承开奖历史。

## 速度
主页面仍然使用当前已经学出的最佳模型做快速预测。
其它4套模型只在后台做影子预测训练，不阻塞网页。

注意：
持续学习可以自动淘汰近期表现差的模型，但彩票开奖结果若接近随机，不能保证命中率会持续上升。
