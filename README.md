# 三分六合彩 AI动态融合版 v27.4

这版把AI融合从“训练满100期后固定50%”改成真正自动升降。

## 动态融合范围
AI最终参与24码评分的权重自动在：

20% ~ 70%

之间变化。

## 怎么自动升降
程序每期开奖后比较：

1. AI在线最近60期真实24码命中率
2. 当前表现最好的统计模型最近60期24码命中率
3. AI最近12期命中率
4. 统计模型最近12期命中率

60期作为主要依据，12期作为快速反应。

如果AI持续更好：
- 35%
- 42%
- 50%
- 60%
- 最高70%

会逐步提高。

如果AI开始变差：
- 50%
- 42%
- 35%
- 28%
- 最低20%

会自动下降。

## 为什么不允许0%或100%
- 最低20%：AI仍然保留学习价值
- 最高70%：统计转移、冷热、生肖二选、长期历史继续兜底

这样不会因为短期几次命中就把全部选择交给AI。

## 小样本保护
实盘AI预测少于5期时：
固定使用35%融合。

之后才根据真实开奖前锁定预测自动升降。

## 页面会显示
- AI滚动训练 100/100
- 当前动态融合 xx%
- AI最近60期实盘命中
- 对比的统计模型及其60期命中
- 最近12期双方命中
- 自动提高/自动降低/保持中等融合的原因

例如：

AI滚动训练 100/100 · 动态融合 58%
AI实盘 61.7% · 对比平衡 53.3%
AI近期优于平衡，自动提高融合
最近12期 AI 66.7% / 对比 50.0%

## 训练与验证
- AI训练窗口：最近100期，每期开奖后重新滚动训练
- 实盘验证窗口：最近60期
- 快速反应窗口：最近12期
- 动态融合：20%~70%

这些都会自动更新，不需要手工调整。
