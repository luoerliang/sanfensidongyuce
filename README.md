# 三分六合彩 冷热头数自适应版 v18

在 v17 基础上加入“冷肖/冷码防守 + 条件转移 + 头数走势”。

## 冷肖/冷码
- 计算号码遗漏期、近12/36期出现率、生肖遗漏期
- 平时仍以每肖两个近期最热码为主
- 只有出现“冷反弹”信号时，才允许某一肖从“两热码”变为“1热 + 1冷防守”
- 冷码不能只因为很久没开就自动加分，必须同时满足历史条件和当前分数接近

## 牛 / 马 / 羊后的冷码假设
程序不会写死“牛马羊后一定开冷码”。
它会用历史转移样本验证：
- 上一期特码生肖为牛/马/羊
- 下一期特码是否属于此前12期没出现的冷码
- 与所有普通期的冷码基准率比较

只有：
- 样本数至少18
- 条件冷码率比基准高至少7个百分点
才启用“牛马羊后冷反弹”增强。

页面会显示：
条件样本数、条件冷码率、基准冷码率。

## 0头 / 4头判断
头数：
- 0头 = 01~09
- 1头 = 10~19
- 2头 = 20~29
- 3头 = 30~39
- 4头 = 40~49

程序比较 8/16/36/80 期走势，并按每个头理论号码数量做归一化。
如果0头或4头明显偏弱，页面显示例如：
`0头偏弱（降权）`

注意：
不会把整个0头/4头全部硬删除，只会降低评分，避免走势突然反转时全漏。

## 24码 / 4肖
- 24码继续固定：12生肖 × 每肖2码
- 每期开奖后重算
- 4肖继续一肖一码，每期重新排序
- 4肖/主码可受冷热、生肖动量、头数降权等共同影响
- 不随机强制换码

## 历史继承
完整保留上一版机制：
- 启动优先从上一在线版本 `/api/export` 迁移机器人已收录历史
- WAL / 防锁 / 内存缓存 / Webhook
- 新开奖先秒显，模型后台重算

升级时不要先停当前服务；确认新版本最新期号和历史总数正确后再切换。
