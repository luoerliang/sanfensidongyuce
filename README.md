# 三分六合彩 前瞻转移预测版 v19

这版专门解决“开什么，下一期才把它加进去”的追码问题。

## 核心变化：预测下一期，不追刚开结果
v18 的短期热度会明显受到刚刚那一期影响，所以视觉上容易出现：
刚开某码 -> 下一期候选才把它抬高。

v19 改成：
1. 当前最新期开奖只作为“状态条件”
2. 直接频率统计从上一期之前开始（排除刚开这一期的直接热度）
3. 从历史中寻找和当前状态相似的开奖：
   - 上一期同号码
   - 同生肖
   - 同头数
   - 同波色
   - 同大小
   - 同单双
   - 前两期生肖/头数组合
4. 看这些历史状态之后“下一期实际开什么”
5. 用这些“状态 -> 下一期结果”给号码、生肖、头数、波色、大小、单双打前瞻分

因此最新开奖号不会因为“刚开”就自动获得最高热度。

## 防追涨
- 刚开的特码有轻微冷却扣分
- 刚开的生肖有轻微冷却扣分
- 但如果历史转移模型显示连续开/重复开确实有优势，转移分仍可以把它重新选回来

不是强制排除重复号，也不是简单反着买。

## 24码
- 继续 12生肖 × 每肖2码 = 24码
- 每肖两个码按“下一期前瞻分”排序，而不是按刚开结果追涨
- 冷码防守、牛马羊条件、0/4头弱势仍保留，但只做辅助

## 4肖一肖一码
- 4肖改成下一期生肖转移 + 趋势综合分
- 每肖主码从该肖两个24码中取前瞻分最高者
- 每期开奖都重算

## 页面
新增“下一期预测状态”：
- 明确显示预测目标期号
- 显示前瞻转移样本量
- 标明“前瞻一阶转移 + 趋势（不追上期）”

## 历史继承
完整保留上一版本历史迁移、Webhook、WAL、防锁、秒显、后台重算。
升级前不要停当前在线版本；新版本确认最新期号和历史总数正确后再切换。
