# 三分六合彩 24码自校准版 v15

本版按最新要求升级，同时保留 v14 的历史继承/WAL/Webhook/缓存机制。

## 24个动态特码
- 从22码提高到24码
- 不是简单取评分前24
- 先把49个号码按历史生肖映射分成12肖
- 每个生肖至少1码、最多3码
- 总数严格24码
- 每肖优先选择近期综合分最高、出现率高、走势匹配度高的号码

因此24码天然覆盖12肖，不会出现候选集中在少数生肖。

## 4肖 · 一肖一码
- 只选4个动态生肖
- 每个生肖只对应1个主码
- 4个主码全部来自24码候选
- 4肖和4码严格一一对应，不再“一肖多个码”混在主攻区

另外页面单独显示“24码 · 12肖分配”，能看到每个生肖的1~3个候选。

## 自动校准模型
提供多个模型配置：
- 趋势快
- 平衡
- 热码
- 结构
- 均衡覆盖

每次新期开奖后，用已经发生的近期历史做滚动比较，自动选近期表现较好的模型用于下一期。
不会随机换模型。

## 命中率
显示：
- 24码命中率
- 4肖1码命中率
- 4肖命中率

验证采用“先用更老的数据选模型，再验证最近60期”的分离方式，减少把未来结果偷看进模型的情况。

不能承诺稳定70%。
24码随机覆盖基线本身约为24/49≈49%，4肖随机基线约为4/12≈33%。
程序会尽量提升真实滚动验证结果，但不会为了显示70%而修改统计口径或伪造命中率。

## 历史继承
完整保留 v14 的机制：
- SQLite WAL
- 内存缓存
- Webhook
- 新版本启动优先从上一在线版本 `/api/export` 继承机器人已收录数据
- HISTORY_SOURCE_URL 作为备用迁移源

升级时旧服务不要提前停；确认新服务最新期号/历史总数正确后再停旧服务。
