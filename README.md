# 三分六合彩 真实校准增强版 v25

截图里的16.7%并不代表稳定命中率。
上一版为了速度，把后台回测缩成了6个样本：
1/6 = 16.7%，0/6 = 0%。
这种样本太小，波动极大，不适合拿来判断模型好坏。

v25修正：

## 1. 24码直接优化“每肖2码”的真实问题
由于24码固定为12生肖×每肖2码，真正决定24码命中的关键是：
“实际特码生肖确定后，该生肖4~5个号码里选的两个有没有包含特码”。

因此v25增加“生肖内二选”模型：
- 近24期
- 近80期
- 近240期
- 近700期
- 贝叶斯平滑，防止一两期短 streak 把排名带偏
- 与下一期状态转移分组合
- 近期预测权重66%，生肖内稳定历史权重34%

## 2. 自动校准不再只看1期
v24为了速度把模型校准缩成1个样本，所以会出现“最近校准分0%”。
v25改成后台10期校准，并且不阻塞网页。
模型每18期才重新校准一次。

## 3. 回测不再只看6期
后台滚动验证改为24期。
网页明确显示：
`验证 N 期 · 24码随机覆盖基线约49%`

这样16.7%、0%这类数字不会再被误解成稳定长期准确率。

## 4. 速度不退回分钟级
- 实时预测仍只跑近1200期窗口
- 全历史仍使用后台缓存先验
- 校准和回测全部后台运行
- 网站和每期开奖后的下一期预测不等待回测完成

说明：
24个号码覆盖49个号码，完全随机选择的理论覆盖率约24/49≈49%。
任何真实提升都应该用足够多的未来滚动样本验证；程序不会把命中率数字人为调高。
