# 三分六合彩 自适应动态版 v9

本版在 v8 基础上加入“自适应动态换码”，并强化开奖结果展示。

## 自适应动态换码
不是强制随机换号码。
模型每期比较：
- 最近10 / 20 / 50期
- 近期相对前一阶段的趋势加速度
- 当前评分与上一期评分变化
- 22码临界排名附近的上升/下降号码
- 最近统计波动程度

当近期结构变化较快时，模型自动提高敏感度；
变化较小时则保持稳定，不为了“看起来变化”而乱换。
网页会显示“本期自适应换码 X 个”。

## 页面
- 左上角实时录入
- 明确显示“开奖结果”
- 最新7码按红/蓝/绿波色显示，最后一个为特码
- 22特码一键复制
- 候选号码小尺寸
- 4肖与4码同屏
- 近60期严格滚动回测命中率/错误率
- 历史期数放最下面，可iPhone手指上下滚动

## 重要
波色只负责界面颜色，不参与特码和4码评分。
历史滚动命中率不是未来中奖概率，也不保证预测结果。
