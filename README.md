# 三分六合彩 AI滚动100期训练版 v27.3

这版按最新要求改成：

**每期开奖后，不只是学刚刚这一期。AI会重新扫描“最近100个已完成期”，滚动训练一次，然后才放出下一期预测。**

## 每期开奖后的自动流程
1. 新期开奖入库
2. 结算上一期锁定预测
3. 读取最近约360期作为训练上下文
4. 取其中最近100个“已完成目标期”
5. 按时间从旧到新重新训练AI
6. 每个训练样本只能看到它之前的历史，不能看到自己的结果
7. 完成100期滚动训练
8. 保存新AI权重
9. 重算下一期24码
10. 重算4肖一肖一码
11. 重算平特一肖
12. 锁定下一期预测等待开奖验证

## 为什么每次重训最近100期
以前是一期开奖只更新一步，适应速度慢。

现在采用“rolling 100”：
- 新一期进来
- 最近100期窗口整体重新训练
- 更老的一期自然退出训练窗口
- AI始终针对最近约100期的当前走势
- 不会把很久以前的旧走势无限重复累加

这比“每期只学习1次”更符合三分钟高频开奖的需求。

## 防止重复训练导致偏掉
v27.3每次100期重训从中性AI权重重新拟合。
不会拿昨天已经训练过100次的权重，再把同100期机械重复加100遍。

长期历史仍然通过“全历史先验”特征进入模型，所以重置短期AI并不等于丢掉全部历史。

## AI融合
- 训练窗口不足时约20%起
- 100期训练窗口完整后最高约50%
- 另一部分仍由统计转移、生肖内二选、冷热、长期历史等模型兜底

## 60期验证不变
训练窗口是100期。
真实前瞻验证窗口仍然是最近60期。

这两个用途不同：
- 100期：给AI学习
- 60期：验证AI最近实盘效果

## 页面自动显示
- AI滚动训练 N/100期
- AI融合百分比
- 实盘24码 N/60
- 100期重训次数
- 上一次100期重训耗时
- 正在扫描100期训练 / 训练完成

注意：滚动训练能让模型更快适应近期数据，但彩票开奖若近似随机，增加训练并不保证未来命中率必然提高。
