# 三分六合彩 实时秒更版 v16

修复：日志已经显示 `inserted issue=...`，但网页仍停留上一期。

原因：
v15 在新期开奖入库后，会先清空页面模型缓存，再启动很重的“模型自动校准+24码重算”。
自动校准要跑多组历史回测，可能需要较长时间，因此页面在模型完成前会显得停在上一期。

v16 改成两阶段更新：

1. 收到新期开奖并写入 SQLite 后
   - 立刻把“最新期号 / 最新7码 / 特码生肖 / 下一期”写进内存页面缓存
   - 网页最快约0.5秒就能显示最新期开奖
   - 页面显示：`新期开奖已入库 · 模型重算中`

2. 后台继续算
   - 24码
   - 4肖一肖一码
   - 12肖1~3码分配
   - 波色/大小/单双走势
   - 模型校准
   算完后无刷新页面即可自动替换成新预测，并显示 `模型已更新`

性能：
- 前端0.5秒读一次内存，不碰SQLite
- 历史缓存继续使用WAL
- 自动校准不再每期完整跑5套历史回测
- 每12期重校准一次模型类型
- 每一期仍会重新计算24码和生肖候选

历史继承：
完整保留v14/v15的上一版本 `/api/export` 自动迁移机制。
升级前不要提前停旧服务；确认新版本最新期号和历史总数正确后再停旧服务。
