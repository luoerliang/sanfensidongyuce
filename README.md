# 三分六合彩 AI全自动更新版 v27.2

这版把该自动更新的全部统一成自动更新，不需要手工刷新或手工触发。

每期开奖到达后，自动执行：

1. 开奖写入数据库
2. 结算上一期已经锁定的AI预测
3. 更新AI权重
4. 更新AI训练次数
5. 更新AI融合比例
6. 更新最近60期AI实盘命中率
7. 更新5套模型最近60期结算成绩
8. 自动选择当前表现较好的模型
9. 重算下一期24码
10. 重算4肖一肖一码
11. 重算平特一肖
12. 更新冷热、头数、波色、大小、单双
13. 保存下一期AI/影子模型预测
14. 页面自动刷新状态

新增 `/api/auto-status`，网页每1秒读取一次轻量状态，所以：
- AI训练次数
- AI融合百分比
- AI实盘24码
- 模型结算 N/60
- 当前下一期
- 自动更新状态

都会自动变化，不需要刷新整个网页。

页面主预测仍每0.5秒读取内存缓存。
统计每10秒更新。
历史列表每5秒更新。

如果自动流程异常，页面会直接显示“异常”，同时 `/api/auto-status` 会返回 last_error。

注意：
自动更新不等于保证命中率提高。AI会持续训练，但彩票若接近随机，实际成绩仍应以60期真实前瞻结果判断。
